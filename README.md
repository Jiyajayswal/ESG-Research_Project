# ESG Report Annotation and Evidence Analysis

A research project focused on developing and evaluating structured annotation methods for extracting sustainability-related evidence from corporate reports.

## My Role

As an Undergraduate Research Assistant, I contributed to the annotation and quality-assurance workflow for sustainability reports. My work included reviewing documents, identifying relevant evidence, applying a structured annotation framework, auditing existing annotations, and helping improve annotation consistency.

I also contributed to the development and refinement of annotation guidelines and supporting documentation to help standardize the process across the research dataset.

## Work Completed

* Reviewed and annotated sustainability-related information from corporate reports
* Applied structured evidence and classification guidelines
* Audited existing annotations for consistency and accuracy
* Identified and documented annotation issues and edge cases
* Contributed to ontology and annotation guideline development
* Used Python and data-processing tools to support research workflows and quality checks
* Helped improve the organization and consistency of the research dataset

## Repository Contents

This repository contains documentation and supporting materials that describe my work and methodology. The underlying research datasets, source documents, and confidential annotation files are not included.

## Confidentiality

Research data and annotation files have been excluded from this public repository because they are part of the underlying research project and may contain restricted or non-public materials.
